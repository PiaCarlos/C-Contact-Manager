# C++ Contact Manager

This project is a simple command-line contact manager written in C++.

It allows users to add, display, search, update, delete, and analyze contacts using arrays, structs, pointers, function overloading, and recursion.

## Features

- Add new contacts
- Display all contacts
- Search for contacts by name
- Update a contact's phone number
- Update a contact's phone number and email
- Delete contacts
- Count contacts by email domain
- Display contact statistics

## Concepts Used

- Structs
- Arrays
- Pointers and pointer arithmetic
- Function overloading
- Recursion
- Pass-by-reference
- Basic command-line menus
